# Тесты API для Stellar Burgers

## 📋 Описание

Проект содержит автотесты для проверки API-методов сервиса **Stellar Burgers**.

### Реализованные проверки

#### 👤 Создание пользователя
- ✅ Уникальный пользователь успешно создаётся.
- ✅ Попытка создать уже зарегистрированного пользователя возвращает ошибку.
- ✅ При отсутствии одного из обязательных полей (`email`, `password`, `name`) возвращается ошибка.

#### 🔐 Авторизация пользователя
- ✅ Вход с корректными логином и паролем проходит успешно.
- ✅ При неверных данных входа возвращается ошибка.

#### 🍔 Создание заказа
- ✅ Заказ создаётся с авторизацией и валидными ингредиентами.
- ✅ Заказ создаётся без авторизации и валидными ингредиентами.
- ✅ Ошибка при отсутствии ингредиентов.
- ✅ Ошибка при передаче невалидного хеша ингредиента.

---

## ▶️ Как запустить тесты

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
    ```
2. Запустите тесты:
    ```bash
   pytest ./tests/ --alluredir=allure_results
   ```
3. Откройте отчет:
    ```bash
   allure serve allure_results/
   ```
